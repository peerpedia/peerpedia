# Obsidian 官方渠道适配：本地实施结果

截至 2026-11-25，正式插件已完成三文件分发和浏览器渲染迁移，并通过隔离 Obsidian 的写作、预览与发布流程验收。它仍是本地候选版本，尚未提交官方收录、发布或替换用户正在使用的插件。当前支持 Apple Silicon macOS、Obsidian Desktop 1.15.1+。

## 已落实的修改

| 范围 | 结果 |
| --- | --- |
| 渲染复用 | `packages/peerpedia-renderer` 成为共同实现；网站保留兼容导出，插件使用浏览器入口；主题继续来自 `packages/peerpedia-theme` |
| 运行方式 | 插件使用自身管理的 Worker 队列；取消只作用于对应请求，闲置后回收，卸载时清理；无需外部 Node 渲染进程 |
| 图表与字体 | TeX/WASM、资源、字体和主题在构建时嵌入；使用原有编译器和前导，不另写图表语法 |
| 上游适配 | 两个固定版本的显式补丁提供资源加载和浏览器计时器兼容；移除构建时字符串改写；这些不是上游已发布接口 |
| 凭据 | 接入 Obsidian SecretStorage；设置只保存引用；存储不可用时仅本次会话保存；旧 Keychain 不自动读取或删除，升级后重新连接一次 |
| 安装包 | 仅 `main.js`、`manifest.json`、`styles.css`；第三方声明随 CSS 分发；英文安装和使用说明已更新 |
| CI | 增加共享包检查，要求三文件实机离线验收和发布验收；pgserver 所在任务使用 Python 3.12；部署门槛包含插件检查 |

最终本地候选包共 **20,337,330 字节**：main.js 20,161,238，manifest.json 345，styles.css 175,747。这是磁盘产物大小，不是内存占用测量；本轮不据此声称已完成全面性能优化。

- 共享渲染包：5 项通过；网站渲染：13 项通过。原型与网站的样例 DOM、标题和引用目标一致；无效 TikZ、超时及恢复验收通过。

- 最终三文件包的真实 Obsidian 离线验收：原生编辑、高亮预览、公式、TikZ、跨章跳转、嵌入字体通过；未尝试 HTTP(S)，未启动外部渲染器；卸载后插件 Worker 为 0。

- 锁文件全新安装后两处补丁应用成功；类型、显式函数类型、格式、Python 检查、版本标签及部署门槛回归通过。

## 宿主文件接口实验的结论

真实 Obsidian 的 `Vault.process` 普通写入和基于旧内容的检查通过。但是：

1. 预先打开的文件描述符在写入完成后仍可覆盖当前发布路径。
2. 隐藏目录被替换后，Adapter 会继续向替换后的目录写入。

这些结果不足以替代现有原生事务层的两项保护，所以本轮保留它。并未把普通 API 实验包装成完整的多窗口、崩溃恢复等价验证，也没有因为其他插件被收录就声称我们的原生组件可获批准。

## 下一阶段的明确边界

先准备原生组件用途、调用范围、构建来源和上述对照结果，确认官方渠道对它的接受方式；同时整理可供审核的插件仓库根目录、元数据、版本映射、许可证材料及标准 release 附件。补丁尚未提交上游，依赖声明清单也不等同于完整的许可证兼容性结论。完成这些准备后再申请收录。

原有九项质量计划中的性能预算、更多增量处理与后续复用工作仍需继续；本报告只记录本次正式插件迁移，不表示整份质量计划或官方上架已经完成。

## 同日清理：删除退役实现

删除旧 Node 渲染客户端、标准输入输出入口、磁盘图表缓存清理器、独立渲染器打包脚本，以及 Swift Keychain 辅助程序和旧凭据适配器。请求处理器直接使用共享渲染包类型；连接界面移除旧 Keychain 保存方式的不可达分支，保留升级提示。

相同统计口径（含空行/注释，排除依赖、产物、文档），插件功能代码由 **9,990 行降为 9,586 行**，净减 **404 行**；也比迁移前的 9,756 行少 170 行。这是源码精简；旧路径此前已不进入正式插件运行，不能据此宣称运行内存或安装包同比缩小。

验证迁移而非仅删测试：书籍渲染、错误诊断、UTF-16 定位及大小限制进入 `render-request.test.ts`；取消、超时、崩溃、非法响应和卸载检查使用浏览器客户端测试；凭据存储与删除失败由 HostCredentials 测试及实机验收覆盖。外部 Node 进程、旧磁盘缓存和 Swift 辅助程序专属断言随实现退役。当前插件套件 **262 项通过、2 项默认跳过**；Django、三文件离线写作、完整发布流程和原生冲突/重启恢复实机验收另行通过。

性能基准已迁入隔离 Obsidian，使用生产 BrowserRendererClient；1/8/32/64 章及连续输入场景跑通，退出后无残留 Worker。当前测试只给出单次样本，不作为优化幅度结论。命令和测量边界见 [基准说明](../../../obsidian/bench/README.md)。清理证据在 `.preview/cleanup/`，未修改真实 Vault、账号或部署。

## 同日复用：保持功能的下一轮收敛

- 主题已嵌入构建产物，删除 `readTheme` 无用的 Adapter/路径参数及其跨窗口传递，直接同步取得资源。
- 书目合并直接复用 `parseBibliography` 返回的已校验 YAML 文档，避免先调用 `readEntries` 再解析同一份源码。编辑/合并的严格校验与输入期间容忍未完成内容的诊断仍分开；没有缓存可被修改的 YAML AST。
- 写作检查、补全、论文目录与预览转换借用同一个插件级 LanguageWorker，复用其中的源码分析缓存。只有插件卸载会关闭它；取消只撤回对应请求的结果，已开始的同步分析可能继续至结束。迟到结果被忽略，其他调用者不被终止。图表渲染仍使用独立的 BrowserRendererClient。
- 删除不再拥有资源的 `preview/runtime.ts`；PreviewController 只撤回自己的请求，插件负责共享渲染服务的释放。性能基准相应明确释放自己创建的渲染客户端。

功能代码同口径从 **9,586 行降到 9,568 行，净减 18 行**。这轮主要减少重复实例、解析及生命周期分工，未测量也不声称整体内存降低了某个百分比。

### 补全复用验证的边界

对锁定的 `bananamark-codemirror@0.1.0` 公共 `completionSources` 做了六项样例对照。普通定理与一个已有闭合环境样例匹配；另外四项不同：

| 现有行为 | 直接采用上游结果 |
| --- | --- |
| 光标后保留已有标题，补全环境名 | 不提供候选 |
| 四冒号嵌套围栏保持其长度 | 不提供候选 |
| 已有代码块闭合围栏 | 重复插入闭合围栏 |
| `\frac` 补全保留已有参数 | 额外插入空参数 |

此外，其候选应用通过 CodeMirror 视图回调执行，不能原样通过 Worker 传递给 Obsidian 原生建议框。没有为复用而引入伪造视图或额外上游补丁；继续保留本地输入适配，使用现有的上游语法、命令数据、公式定位及环境匹配函数。对照输出在 `.preview/reuse/completion-probe.log`，现有输入行为仍由 `language.test.ts` 约束。

新增回归覆盖共享语言请求的独立取消、不同论文同名路径的引用隔离，以及关闭一个预览不会释放另一预览正在使用的服务。一次全量测试暴露原有文件写入用例的5秒限时不稳定；计时显示真实持久化创建约3.76秒、后续弹窗操作约0.15秒，故仅将该真实IO用例限时调整为20秒，保留全部断言。最终验收证据保存在 `.preview/reuse/`。

本轮最终包构建、TypeScript 与显式类型检查通过；插件套件265项通过、2项默认关闭的集成测试跳过。最终三文件包离线宿主验收、独立Django集成测试及迁移后的浏览器基准分别通过。服务共享后的完整发布与原生冲突恢复流程也已通过，随后移除空预览包装层的版本重新完成了离线宿主验收。


## 同日书目精简：统一源码编辑

按用户继续下一步的指示，书目保留搜索列表、YAML 源码编辑、结构校验和安全改键。移除逐字段编辑、新增和删除表单；新增、修改、删除统一使用 **Edit YAML source**，每条文献仅保留安全改键按钮。界面沿用现有模态窗口、按钮和列表样式；使用说明同步更新。

删除这些表单独占的 `patchEntry`、`addEntry`、`removeEntry`、CST 插入/删除辅助函数，以及新增键校验和删除影响分析的 Worker 接口。安全改键仍检查键冲突、YAML 别名、跨章与书目正文引用，并使用原有版本校验和文件事务。源码保存复用 `readEntries`，不增加另一套校验器；它检查 YAML 结构，全文引用和发布语义仍由既有诊断及预览处理。直接编辑 YAML 不会自动更新引用。

同口径功能代码 **9,568 → 9,324 行，净减 244 行**（含空行/注释；统计 `obsidian/src`、`obsidian/renderer`、`obsidian/native` 的代码及 `obsidian/styles.css`；不含测试、依赖、文档和构建产物）。这表示维护代码减少，不作为运行性能或内存节省幅度的结论。

扩展既有真实 Obsidian 离线验收，实际点击验证搜索、源码新增和删除、无效 YAML 的草稿保留/文件不变、修正后保存及跨章改键。首轮发现新增同步校验未进入表单的 Promise 错误处理，已将保存回调改为 async，最终完整流程通过。三文件启用、共享渲染/公式/TikZ、无网络写作、原生编辑器保持和卸载 Worker 清理亦通过；已查看界面截图。证据位于 `.preview/bibliography/final-tests.log`、`final-offline.log` 和 `final-offline/bibliography-list.png`。
