# Security reporting and maintenance

Please report suspected vulnerabilities privately through GitHub's **Security →
Report a vulnerability** for this repository. Do not publish credentials, private
papers, personal information, or working exploits in public issues. Include the
affected version, impact, and a minimal reproduction using your own test data.
Do not load-test or exploit the public service without the owner's explicit approval.

The maintained branch is `main`. Passing tests and dependency scans reduce risk;
they do not constitute a penetration test or guarantee that no vulnerabilities exist.
Security fixes follow the same required backend, browser, quality, and security
checks as other releases. Dependency updates are proposed automatically but require
review and a new deployment. See the README for administrator authentication,
backup recovery, SSH configuration, and the limits of DDoS protection.
